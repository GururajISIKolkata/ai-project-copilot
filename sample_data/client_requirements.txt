CLIENT REQUIREMENTS & COMPLIANCE SPECIFICATION
Client: Bharat Financial Group
Engagement: Enterprise ERP Cloud Migration
Classification: Highly Confidential

1. SECURITY & DATA PRIVACY MANDATES
- All data in transit must be encrypted using TLS 1.3.
- Data at rest must use AES-256 encryption.
- Compliance with RBI digital security guidelines and India DPDP (Digital Personal Data Protection) Act.
- No production financial records or customer PII may be stored in unencrypted staging tables.
- Role-Based Access Control (RBAC) must enforce least-privilege principles across all ERP modules.

2. SYSTEM AVAILABILITY & SLA
- Production ERP system uptime SLA is set at 99.95% during business hours (08:00 to 22:00 IST).
- Disaster Recovery Objective: RPO (Recovery Point Objective) <= 15 minutes, RTO (Recovery Time Objective) <= 2 hours.

3. GO-LIVE AND CUTOVER CRITERIA
- Zero critical or high-severity security vulnerabilities allowed at cutover.
- All User Acceptance Testing (UAT) test scripts must achieve a 100% pass rate signed off by business stakeholders.
- Final go-live date is strictly December 15, 2026. Slippage beyond this date will incur contractual penalties.
